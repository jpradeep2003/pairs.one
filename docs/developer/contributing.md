# Contributing

Prefer reusing existing templates, CSS classes, and Elm programs. On `/user`, the custom-game widget is locked to 1 player and local mode (`data-lock-solo-local`).

After code changes, refresh Graphify: `graphify update .`

After substantial chats, run `python3 scripts/build-dev-history.py`.

Locales: [Translations](i18n.md).
