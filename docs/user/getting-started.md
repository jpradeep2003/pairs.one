# Getting started

1. Open the site (local URL or https://pairs.pspark.online if the tunnel is up).
2. Use the home page for solo, random, friend, or local multiplayer.
3. Open **My games** (`/user`) for a 1-player local custom game. Pick theme and size only.
4. When the round ends you return to **My games**. History shows Accuracy (%), Duration, Hits, Misses, Neutral, Theme, Size, Start, and End. Remove a row with ×.

History stays in this browser only.
