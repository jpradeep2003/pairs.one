# Getting started

1. Open the site (local or the HTTPS hostname).
2. Use the home page for solo, random, friend, or local games.
3. Open **My games** (`/user`) for a custom game that remembers your last theme, size, player count, and visibility.
4. After you finish a round, return to **My games** to see score, duration, times, theme, and board size.

History stays in this browser only.
