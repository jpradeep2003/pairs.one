# Translations

If you add or update a locale (example: French):

## First time

1. `mix gettext.merge priv/gettext --locale=fr`
2. Edit `priv/gettext/fr/LC_MESSAGES/default.po`
3. Add `assets/elm/I18n/Fr.elm` (see `assets/elm/I18n/En.elm`)
4. Update `assets/elm/I18n.elm` (import and case)
5. Copy `lib/pairs_one_web/templates/page/index.en.html.eex` to `index.fr.html.eex` and translate
6. Add `fr` to locales in `config/config.exs` and a label in `lib/pairs_one_web/views/layout_view.ex`

## Later updates

- Refresh the `.po` file, `I18n/Fr.elm`, and the HTML template if the English landing page changed. Keep a previous translation aside to reuse strings.

Confirm the app compiles and runs before opening a PR.
