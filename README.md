# pairs.one

Self-hosted source for the multiplayer concentration game originally published at https://pairs.one, plus a `/user` page for remembered custom games and local history.

## Quick start

1. Install Elixir, Elm 0.18, Node, and Redis — [Developer setup](docs/developer/setup.md).
2. Start the app: `scripts/start-local.sh` then open http://127.0.0.1:4000
3. Optional public HTTPS: [Operator start/stop](docs/operator/operations.md)
